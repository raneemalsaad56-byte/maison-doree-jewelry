# Maison Dorée - Luxury Gold Jewelry Showcase

A responsive gold jewelry showcase built with HTML5, CSS3, and Bootstrap for showcasing gold collections, daily gold karat rates, direct WhatsApp inquiries, and showroom location.

## Key Features
- Luxury gold and dark contrast theme
- Mobile-first responsive layout across mobile and desktop screens
- Live gold karat price bar (24K, 21K, 18K)
- Direct WhatsApp order and inquiry buttons
- Embedded showroom map and contact section

## Built With
- HTML5
- CSS3
- Bootstrap 5
